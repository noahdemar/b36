# B-36 Multicrew - Project Spec

In-browser game for multicrew B-36 Peacemaker missions. The 3D model is the core asset.

## Decisions (confirmed with user, 2026-10-18)

| Topic | Decision |
|---|---|
| 3D model source | Blender-authored glTF, generated by Python scripts (headless `bpy` via uv) |
| Interior | Full walkable interior: forward compartment, tunnel + trolley, aft compartment |
| Networking | Single-player first: one player can switch between all stations. Networking later |
| Fidelity | Moderate: believable flight model, engine management, nav, radar bombing, gunnery |
| Variant | B-36H (proposed): full defensive armament gives gunner stations. Confirm with user |

## Architecture

```
b36/
  SPEC.md
  tools/model/        uv project; bpy scripts that generate the aircraft
    params.py         all dimensions, each tagged SOURCED / DERIVED / ESTIMATED
    build_b36.py      generates the scene and exports web/public/models/b36.glb
    render_previews.py  Cycles CPU renders for review
  web/                Vite + TypeScript + three.js client
```

- Model is fully procedural and parametric: change params.py, regenerate, reload.
- Coordinates (Blender): +Y forward (nose), +X right wing, +Z up, meters. Origin at fuselage
  centerline, mid-length. glTF export converts to Y-up with nose toward -Z (three.js forward).
- Animated parts are separate nodes with origins on their hinge/rotation axis and local X aligned
  with the hinge: ailerons, flaps, elevators, rudder, 6 props, bomb bay doors, turrets, gear.
- Naming convention for nodes: `Prop_L1..L3/R1..R3`, `Aileron_L`, `Flap_R2`, `Elevator_L`,
  `Rudder`, `BombDoor_B1_L`, `Turret_*`, `Gear_*`. The client looks parts up by name.

## Reference data

Sourced (NMUSAF via Wikipedia, B-36J-III spec block):
- Length 49.40 m, span 70.10 m, height 14.25 m, wing area 443.3 m2
- Airfoil NACA 63(420)-422 root, 63(420)-517 tip
- Max wing thickness 7.5 ft (2.3 m) -> root chord derived as 2.3 / 0.22 = 10.4 m
- Dihedral 2 deg, incidence 3 deg, washout 2 deg
- 6x R-4360 pusher, 3-blade 19 ft (5.8 m) props; 4x J47 in 2 pods outboard of piston engines
- Crew 15 (H model), forward and aft pressurized compartments joined by tunnel with trolley
- 4 bomb bays
- Fuselage diameter: one text source says 3.5 m; the three-view measures 3.75 m (used)

Measured from the General Dynamics three-view (reference/MEASUREMENTS.md): fuselage profile
(3.75 m dia), canopy, wing planform, nacelle/jet pod stations, fin contour, tailplane planform.
Verified by tools/model/compare_blueprint.py overlays.

Still estimated: gear geometry, turret positions, bomb bay stations, control surface spans,
jet pod length and drop.

## Phases

1. Exterior model v2: geometry matched to three-view and photos, materials, animated part
   hierarchy, GLB export, renders, three.js viewer. (done)
2. Exterior v3: UVs, baked panel lines/rivets/insignia, LODs, detail (antennas, exhausts, frames).
3. Interior: walkable compartments, stations (pilot, copilot, engineer, nav, radio, radar-bomb,
   gunners), tunnel trolley, collision.
4. Flight model and systems (moderate fidelity): 6 piston + 4 jet engines, fuel, flight controls.
5. Stations gameplay: nav, radar bombing, gunnery, missions.
6. Networking: authoritative server, station ownership, sync.
